PROYECTO PERSONALTERMINADO · RESPONSIVO

Portergram

Una red social Full Stack con perfiles, seguimiento, publicaciones, comentarios, stories, chat y mundos interactivos.

Angular 21TypeScriptNode.jsExpressMongoDBSocket.IOJWT

Cómo funciona

Angular organiza las vistas y consume rutas protegidas mediante JWT. La API guarda usuarios, relaciones y contenido en MongoDB. Socket.IO transmite mensajes y presencia en tiempo real. «Mi Mundo» traduce la actividad del usuario en reglas, eventos, niveles y etapas visuales de progreso.

Retos y soluciones

El diseño de escritorio desbordaba en varios anchos y el jardín perdía el desplazamiento vertical: revisé rejillas, puntos de ruptura, navegación y controles táctiles en móvil y tablet. En el backend corregí un registro duplicado del modelo de comentarios que impedía arrancar la API y depuré el motor de niveles y sus eventos.

APLICACIÓN FULL STACKEN DESARROLLO

Jornada Laboral

Gestión empresarial de fichajes, pausas, contratos e historial; resúmenes semanales e informes mensuales en PDF.

AngularTypeScriptJava 21Spring BootSpring SecurityMySQLJPA/HibernateMaven

Cómo funciona

La interfaz se comunica con una API Java protegida con JWT. El empleado registra su jornada y la planificación actual permite asignar un turno por trabajador y fecha. Los datos se guardan en MySQL y alimentan el historial y los informes.

Retos y soluciones

Resolví el rechazo de credenciales de MySQL y la falta de metadatos JDBC corrigiendo la configuración y sacando la contraseña del código. Detecté que el puerto 8080 estaba ocupado, arranqué el servidor en 8081 y comprobé la compilación y los tests con Maven.

En ampliación: horarios de lunes a domingo para semana, mes o contrato, cambios diarios y pausas configurables.
