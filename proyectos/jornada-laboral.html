Jornada Laboral

Control de jornada para empresas: fichajes, pausas, contratos, historial, resúmenes e informes PDF.

AngularTypeScriptJava 21Spring BootSpring SecurityJPA/HibernateMySQLMavenJWT

El proyecto

Angular presenta las jornadas y la planificación; una API Java con Spring Boot y Spring Security protege el acceso mediante JWT. MySQL conserva los datos para el historial, los resúmenes semanales y los informes mensuales.

Cómo funciona

El empleado registra entradas, salidas y pausas. La planificación actual permite asignar un turno a un trabajador para una fecha concreta. La programación recurrente de lunes a domingo para semana, mes o contrato, con cambios diarios y pausas configurables, sigue en desarrollo.

Retos y soluciones

MySQL rechazaba las credenciales y Hibernate no podía leer los metadatos JDBC. Corregí la configuración y trasladé la contraseña a una variable de entorno. El puerto 8080 estaba ocupado: identifiqué el conflicto, inicié la API en 8081 y verifiqué compilación y pruebas con Maven.
