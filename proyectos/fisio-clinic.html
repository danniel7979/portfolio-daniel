El proyecto

Proyecto Full Stack orientado a la gestión de reservas. Combina una interfaz React y Next.js con persistencia de datos en PostgreSQL mediante Supabase y Prisma.

Cómo funciona

El objetivo es facilitar la consulta y la solicitud de citas desde una web clara y adaptable.
